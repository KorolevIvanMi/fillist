Greetings everyone! Welcome to version 1.0! To begin, let me remind you why this program was created. It was made for users who want to build their own movie library or plan what to watch and then save their thoughts about it.
What has been changed:

1. An installer file for Windows and Linux has been added, so if you just want to use the application, you can download it from the dist folder.
2. The design has been slightly updated, specifically fonts have been replaced and partial scaling has been implemented (it works adequately only at an aspect ratio of 1920x1080).
